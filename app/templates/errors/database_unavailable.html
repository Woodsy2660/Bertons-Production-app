Database unavailable

The app cannot reach PostgreSQL. Check that the database service is running and that DATABASE_URL is correct.

Local development:

1. Ensure Docker is running.

2. In the project folder, start Postgres:

docker compose up -d db

Or use the helper script:

.\scripts\dev-up.ps1

Production VM:

docker compose --profile full ps
docker compose --profile full logs db

Local Postgres is usually on localhost:5433. Check readiness or retry the dashboard.
