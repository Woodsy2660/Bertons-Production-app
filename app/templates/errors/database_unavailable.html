Database unavailable

The app cannot reach PostgreSQL. On local development this usually means Docker Desktop or the database container is not running.

Start the local stack:

1. Open Docker Desktop and wait until it shows "running".

2. In the project folder, run:

docker compose up -d

Or use the helper script:

.\scripts\dev-up.ps1
